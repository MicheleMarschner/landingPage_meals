# LandingPage Meals

A responsive, modern landing page for a fictional meal delivery service — built with clean HTML, CSS, and JavaScript.

[![Live Demo](https://img.shields.io/badge/live-site-brightgreen)](https://landingpagemeals.netlify.app/)
[![MIT License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

---

## Overview

**LandingPage Meals** is a responsive and visually appealing landing page for a fictional meal subscription service. It’s designed to showcase a premium food delivery business, emphasizing simplicity, mobile-friendliness, and clear calls to action.

Whether you’re learning front-end design or need a template for a food startup, this landing page offers a solid foundation.

---

## Technical Features

- **Responsive design** (mobile, tablet, desktop)
- Eye-catching **hero section** with CTA
- Clean and organized **menu highlights**
- Simple **subscription form**
- Easy to customize layout and styling

---

## Tech Stack

- HTML5
- CSS3 (custom styles, flexbox, media queries)
- JavaScript (form behavior, scroll animations)

## Getting Started

You can view the project live or run it locally.

### 1. Clone the repo

```bash
git clone https://github.com/MicheleMarschner/landingPage_meals.git
cd landingPage_meals
```
### 2. Open index.html in your browser
No build tools or setup needed — it's pure HTML/CSS/JS.
